# 美苏协同交战体系发展路径比较研究

## 项目简介

本仓库收录论文《美苏协同交战体系发展路径比较研究——以"A射B导"体系的反事实推演为中心》，该论文以美苏两国"探测与火力分离"作战能力为研究对象，比较两套协同交战体系在相同技术条件下的路径分化，并用反事实推演补全1991年因苏联解体而中断的那一半比较。本文为学术性反事实推演研究，第六章关于 2026 年体系形态的描述是在设定约束条件下的逻辑推演结果，不构成事实陈述、情报评估或预测。全部资料来源于公开文献。

### 核心研究问题

冷战末期，美国和苏联面对的是同一批技术条件——相控阵雷达已经成熟，数字数据链可以实用化，空空导弹和地空导弹开始装备主动雷达导引头——为什么两边最终走出的路径差别如此之大？

### 研究方法

- **历史比较法**：按时间顺序重建美苏双方在1991年前后已经具备的技术条件
- **反事实推演**：遵循Lebow提出的操作规范，设定技术继承链、工程周期、体系哲学延续三项约束，推演冷战延续情境下双方到2026年的体系形态
- **双向验证**：将推演结果与苏联解体后俄罗斯体系的真实退化过程进行对照

### 主要发现

1. 1991年双方在体系构想上的差距远小于通常叙述，苏联防空体系在架构层面已具备探测与火力分离的骨架
2. 美国的优势集中在把地理分散的雷达数据合成为单一火控级航迹图这一项工程能力
3. 体系设计逻辑是解释这场技术竞争结果的一个独立变量，与技术水平高低并不等同
4. 在双方均保有二次打击能力且对彼此客场劣势判断准确时，协同交战能力若在两个超级大国之间同步成熟，其净效应可能是抑制而非鼓励先发制人

### 关键词

协同交战能力、A射B导、反事实推演、攻防平衡、美苏军事竞争
